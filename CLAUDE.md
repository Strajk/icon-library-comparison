# Project Instructions

## Icon Library Comparison Tool

- ABSOLUTELY NO INLINE SVGs in script.js
- All icons must be loaded from actual SVG files in the icons/ directory structure
- Use fetch() or other appropriate methods to load SVG content dynamically
- Do not hardcode SVG content within JavaScript functions

## Directory Structure
- `icons/lucide/` - Lucide icons
- `icons/tabler/` - Tabler icons  
- `icons/heroicons/` - Heroicons
- `icons/phosphor/` - Phosphor icons
- `icons/feather/` - Feather icons
- `icons/hugeicons/` - HugeIcons

## Icon Loading
- All icons should be loaded dynamically from their respective SVG files
- Icon mappings should reference actual file names that exist in the directories
- Verify icon existence before attempting to load
