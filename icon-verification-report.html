HugeIcons Analysis

The HugeIcons are currently being rendered as CSS classes but should be rendered as SVG files.

Solution:

Update the createIcon function to load SVG files directly for HugeIcons instead of using CSS classes.

// Change this:
iconDisplay.innerHTML = `<i class="hgi-stroke hgi-${iconName}"></i>`;

// To this:
iconDisplay.innerHTML = getHugeIconSVG(iconName);
